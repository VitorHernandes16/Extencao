O código por trás do vício.

Você já achou que era "falta de força de vontade" ficar horas no celular. Na verdade, é engenharia de software — funções escritas de propósito pra isso acontecer. Aqui você lê o pseudocódigo real.

01

scroll_infinito.js

feed

O feed nunca "acaba" de propósito. Não existe uma tela de fim de conteúdo — o app sempre carrega mais um post, mais um vídeo, mais um card.

1enquanto (usuario == "online") {
2 carregar(proximo_conteudo);
3 // nunca retorna null
4 // nunca existe "fim do feed"
5}
revelação: a decisão de "parar de rolar" foi retirada do fluxo. Quem decide quando parar é você — não a interface — mas ela é feita pra nunca te lembrar disso.
02

recompensa_variavel.js

notificações

O mesmo algoritmo por trás das máquinas caça-níqueis de cassino. A recompensa chega de forma imprevisível — e é isso que mais ativa a dopamina.

1se (aleatorio() < 0.3) {
2 notificar(agora);
3} senao {
4 atrasar(minutos_aleatorios);
5 // você espera sem saber quando
6}
revelação: recompensa previsível vicia pouco. Recompensa imprevisível vicia muito — é literalmente a lógica de um caça-níquel, aplicada a mensagens e curtidas.

autoplay.js

vídeo

Quando um vídeo termina, o próximo já começa sozinho. A pausa natural — o momento em que você pensaria "quero mesmo continuar?" — foi removida do código.

1ao_terminar(video_atual, () => {
2 tocar(proximo_video);
3 // decisão do usuário: pulada
4});
revelação: parar exige uma ação ativa (fechar o app). Continuar não exige nada. A inércia foi programada a favor do "continuar assistindo".
04

codigo_etico.js

contraponto

Nada disso é inevitável. O mesmo conhecimento técnico pode ser usado pra devolver o controle ao usuário — é uma escolha de quem programa.

1se (tempo_de_uso > limite_diario) {
2 mostrar_lembrete("Hora de uma pausa?");
3 pausar_autoplay();
4}
revelação: engenharia de software não é neutra — ela carrega a intenção de quem a escreve. Entender o código é o primeiro passo pra escolher por si mesmo.
